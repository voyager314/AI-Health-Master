## ADDED Requirements

### Requirement: FR-S01.9 体重记录的字段契约

`body_metric` 必须（SHALL）含下列字段：

| 字段 | 规则 |
| --- | --- |
| `measured_at` | 测量时刻，即用户点击记录那一刻的设备本地时刻；按 UTC 存储，精确到秒，由程序写入，用户不可编辑 |
| `tz_offset_minutes` | 写入当时的时区偏移，东为正；当日与当周的归属按它判定 |
| `weight_kg` | 体重，统一以 kg 存储，取值 1–500，必须落在 0.1 kg 网格上（至多一位小数）。界面可切换为斤显示，切换不改变存储值 |
| `note` | 备注，不超过 200 字；`null` 表示未填 |

网格校验与其余字段规格一样，由写入与导入共用：离网格的值在写入时被拒绝；导入文件中只要出现一个，整个文件就校验失败。把数值规整到网格是调用方的责任，存储层禁止（MUST NOT）替调用方取整——替它取整，存储值就会与界面显示值不一致，而且这种不一致无从发现。

`body_metric` 不受运动记录保留期的清理（见 FR-S01.8）。

#### Scenario: 一位小数的体重通过校验
- **GIVEN** 一条 `weight_kg` 为 72.4 的体重记录
- **WHEN** 校验这条记录
- **THEN** 通过校验，记录可正常保存与读出

#### Scenario: 离网格的体重被拒绝
- **GIVEN** 一条 `weight_kg` 为 72.45 的体重记录
- **WHEN** 校验这条记录
- **THEN** 校验失败并定位到 `weight_kg`

#### Scenario: 浮点累加得到的近似值同样被拒绝
- **GIVEN** 一条 `weight_kg` 为 70.19999999999999 的体重记录
- **WHEN** 校验这条记录
- **THEN** 校验失败并定位到 `weight_kg`

#### Scenario: 超出取值范围被拒绝
- **GIVEN** 一条 `weight_kg` 为 0.5 或 500.1 的体重记录
- **WHEN** 校验这条记录
- **THEN** 校验失败并定位到 `weight_kg`

#### Scenario: 导入文件中的离网格体重使整个导入失败
- **GIVEN** 一个导入文件中某条体重记录的 `weight_kg` 为 72.45
- **WHEN** 用户导入该文件
- **THEN** 校验失败并指出这条记录的 `weight_kg`
- **AND** 本地数据库未被改动
